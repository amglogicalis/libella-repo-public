📚 Guía Maestra & Onboarding de Libella

¿Qué es Libella?

Libella es el Panóptico Universal del ecosistema Terra: un motor centralizado de observabilidad, monitorización de latencias en series temporales y control de costes cloud (FinOps) que funciona sin servidores permanentes y sin bases de datos de pago.

Los 3 Pasos para Empezar:

  1. Crea un Watchtower: Asigna un centinela para tu aplicación o entorno (ej. E-Commerce Prod).
  2. Conecta tus Lentes: Configura el envío de eventos desde Vercel Log Drains, llamadas de OpenAI, métricas de AWS o peticiones HTTP estándar.
  3. Activa Disyuntores (Circuit Breakers): Define un techo de gasto en dólares o una tasa de error máxima para recibir alertas automáticas.

Almacenamiento $0 Perpetuo:

Los eventos en caliente de las últimas 24h residen en el vault de Git (.libella-storage). El Cronógrafo se despierta periódicamente para resumir y compactar millones de registros en resúmenes estadísticos permanentes sin saturar el almacenamiento.
